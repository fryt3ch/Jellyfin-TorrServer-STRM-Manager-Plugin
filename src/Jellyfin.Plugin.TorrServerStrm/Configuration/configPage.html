TorrServer STRM Manager

Settings

Must be reachable from the Jellyfin server (in Docker, the container name). For example http://torrserver:8090. This address is also written to .strm files.
For playback only through Jellyfin, enable "Force transcoding of remote media sources (like Live TV)" in the Jellyfin user settings. Otherwise clients must be able to reach this address directly for Direct Play.
